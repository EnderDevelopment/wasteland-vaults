# Bóvedas del Yermo Minecraft Plugin

Bóvedas del Yermo is a Fallout-inspired Minecraft plugin that adds command-built bunkers and Vault-Tec shelters, two powered armor sets, usable wasteland weapons, and spawnable enemies. It is a Minecraft plugin for Paper servers, with gear, structures, weapons, and enemies managed through the `/wasteland` command.

## Install

1. Use a Paper server running Minecraft 1.21.11 with Java 21.
2. Download or build the plugin JAR and place it in the server's `plugins` directory.
3. Start or restart the server. The plugin registers the `/wasteland` command when it loads.
4. By default, the plugin permissions are granted to operators: `wasteland.use` and `wasteland.structure`.

## Use

1. Run `/wasteland` in-game to see the available command categories.
2. Run `/wasteland give t45` or `/wasteland give t60` to receive a full armor set and both weapons.
3. Equip all four pieces of the same armor set to enable powered flight and fall-damage immunity. T-60 armor also reduces other incoming damage.
4. Use `/wasteland weapon minigun` or `/wasteland weapon fatman` to get an individual weapon. Right-click to fire. The Fat Man requires mini-nuke charges; the weapon command supplies one.
5. Run `/wasteland structure bunker` or `/wasteland structure vault` to build a structure in front of you. You need the `wasteland.structure` permission. Building replaces blocks in the structure area and teleports you inside; choose a clear location.
6. Run `/wasteland enemy ghoul`, `/wasteland enemy mutant`, or `/wasteland enemy deathclaw` to spawn an enemy nearby. This requires `wasteland.use`.
